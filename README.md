# 🚖 Uber Trip Analytics Pipeline

An end-to-end Data Engineering project built using Python, PostgreSQL, Apache Spark, and Streamlit.

## Features

- ETL Pipeline using Python
- PostgreSQL Data Warehouse
- Apache Spark Analytics
- Interactive Streamlit Dashboard
- SQL-based Reporting

## Tech Stack

- Python
- PostgreSQL
- Apache Spark
- Streamlit
- SQLAlchemy
- Pandas

## Project Structure

```
config/
dashboard/
data/
drivers/
logs/
scripts/
spark/
sql/
```

## Dashboard

Displays:

- Total Trips
- Revenue
- Average Fare
- Average Distance
- Revenue by Payment Method
- Vendor Analysis
- Top Pickup Locations
